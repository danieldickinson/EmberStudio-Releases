# Ember Studio downloads

[Download Ember Studio 0.2.1](https://github.com/danieldickinson/EmberStudio-Releases/releases/tag/v0.2.1) — Apple Silicon (M1 or newer), macOS 27+.

This public repository holds compiled test releases and the signed automatic-update feed. Application source is maintained separately in a private repository.

Open the DMG, drag Ember Studio to Applications, eject the image, then launch. The app includes its browser, video tools and offline AI models; no developer tools are required. Test releases are not Apple-notarised. If the first launch is blocked, use System Settings → Privacy & Security → Open Anyway after attempting to open the app.

Settings → AI processing lets you compare CPU only, Prefer GPU and Automatic on each Mac. Settings → Updates controls signed daily checks and automatic downloads. Ember Studio → Check for Updates checks manually. Updates wait for active jobs before relaunch.

Use the release's INSTALL.txt and SHA256SUMS.txt for installation guidance and checksum verification. The appcast.xml file is cryptographically signed and must not be manually edited.
